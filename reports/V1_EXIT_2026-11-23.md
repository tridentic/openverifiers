### C6 in detail

**OVState** (`state/hash.py`, `state/load.py`, trusted).
- `ov state` writes a scenario's unconditionally derived atoms as canonical
  JSON with a SHA-256.
- `import state "f.json" as n` brings them in as facts with origin `import:n`.
  Tampered files are refused (E208).

**WHY / WHY NOT.**
- WHY shows the checked derivation.
- WHY NOT shows the refutation, the missing facts that block the statement,
  or the derivation if it holds after all.

**`ov gate`.**
- It checks changed OV files with the kernel and runs the gold and meaning
  gates over a range.
- It also runs as a pre-commit hook, a GitHub Action and an MCP tool.
- Exam cases that encode false options as theorems (math p1q7) fail the gate
  by design: their refutations are the answer.

**Condition B: object-layer steps in the trace.**
- Object answers leave JSON records behind their kernel verdicts: accepted
  models, theorem certificates, and uniqueness certificates.
- `checker/objects.py` (trusted) re-decides each record against the *compiled*
  class:
  - invariants, theorems and hypotheses never come from the record;
  - a uniqueness claim's givens come from the compiled query plan;
  - a lemma is accepted only after its own certificate passed earlier in the
    run.
- A rejected record demotes its answer.
- **Mutation test** (`tests/v1/test_object_mutants.py`, 307 mutants of real
  records):

  | outcome | count |
  |---|---|
  | mutants whose claim is false | 121, **all rejected** |
  | unsound mutants accepted | **0** |
  | true claims accepted | 78 |
  | true claims rejected (the checker is conservative) | 101 |
  | not judged by the oracle | 7 |

- During development, a real bug in the new checker was caught: givens were
  read as values, not equations. It was fixed before commit.

**OV-Paper hooks.**
- JSON blueprints per theorem: the statement, who proposed it, the closure by
  role (definition / law / foundation / lemma, exact when certificate-backed),
  steps with roles and `proposed_by`, and lemma boundaries.
- The SUVAT test shows `suvat_s` rests on the displacement definition alone.
