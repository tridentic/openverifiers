### Gap (e): sums and induction

- **`sum(E, i, n)`** is E summed over i = 1..n. The trusted evaluator sums
  directly for a whole n up to 10,000.
- **Closed forms by induction:** a closed form `sum(E, i, n) = F(n)` is
  PROVEN at `{kernel}` by an induction certificate.
  - `raw/certificate.py` checks F(0) = 0 and F(n) − F(n−1) = E(n) by exact
    normal form.
  - It also requires the hypotheses `n: Integer` and `n >= 0`, and a body
    that doesn't mention n.
- **False closed forms** are refuted among small natural numbers, each case
  decided by the trusted evaluator. A query and a class check both give
  REFUTED with the instance n = 1.
- **Three domains** (`tests/v1/test_sums.py`):
  - mathematics: Σi, Σi², Σi³;
  - physics: Galileo's odd-number rule, Σ(2k − 1) = n²;
  - chemistry: shell capacities, Σ2k² = n(n+1)(2n+1)/3.
- **Tests that the checker refuses:**
  - a wrong base hypothesis;
  - a missing integer hypothesis;
  - a body that mentions n;
  - a false F.

### agent.workflow (draft, `drafts/packages/agent/workflow.ov`)

A policy package states `forbidden(tool, target)`, `needs_approval(tool)` and
`approver(role)`. From those, `agent.workflow` derives:
- **Plan verification:** `violation(plan, step)` names each failing step, and
  `valid(plan)` the plan's verdict.
  - On the test repo policy, steps 2 (push to main, forbidden) and 3 (deploy
    approved only by an intern) are named.
- **The gate's verdict on one call:** `refused`, `needs_human` or
  `permitted`.
- **Bounded synthesis:** states reachable from the start within a horizon,
  using permitted calls that need no approval. The plan is a term built by a
  constructor.
  - On the test, it finds run_tests → open_pr → merge and avoids the
    forbidden push to main.

All verdicts are `{kernel}` (rule layer, checked traces).

### The tool-call gate over MCP (`openverifiers.mcp_gate`)

- An MCP server on stdio: JSON-RPC 2.0, standard library only, so no new
  dependency.
- It offers `check_tool_call(tool, target)` against an OV policy file
  (`examples/policies/repo_policy.ov`).
- Each answer is the kernel's verdict on the scenario "this call is
  requested".
- **A tool or target the policy doesn't name is never permitted:** it gets
  `needs_human`, with no trust claimed.
  - Found while testing: an unlisted `rm_rf home` was first *permitted*,
    because closed-world negation finds no `forbidden` fact for it. Fixed
    before commit.
- `tests/v1/test_mcp_gate.py` drives the server as a subprocess. It covers
  initialize, tools/list, five calls, an unknown method and a parse error.
